# IIC / I2C (Inter-Integrated Circuit) Protocol

## Overview

**I2C** (Inter-Integrated Circuit), commonly referred to as **IIC**, is a synchronous, multi-master, multi-slave, packet-switched, single-ended serial communication bus invented by Philips Semiconductors (now NXP). It is widely used for attaching lower-speed peripheral ICs to processors and microcontrollers in short-distance, intra-board communications.

---

## Key Characteristics

- **Physical Bus Lines**:
  - `SDA` (Serial Data Line): Bidirectional line for data transfer.
  - `SCL` (Serial Clock Line): Clock signal generated by the bus master.
- **Topology**: Open-drain / open-collector with external pull-up resistors (typically 2.2 kΩ - 10 kΩ).
- **Addressing**: Standard 7-bit addressing (up to 128 devices) or extended 10-bit addressing.
- **Speed Modes**:
  - **Standard Mode (Sm)**: Up to 100 kbps
  - **Fast Mode (Fm)**: Up to 400 kbps
  - **Fast Mode Plus (Fm+)**: Up to 1 Mbps
  - **High-Speed Mode (Hs-mode)**: Up to 3.4 Mbps
  - **Ultra-Fast Mode (UFm)**: Up to 5 Mbps (unidirectional)

## Protocol Frame Format

```text
+-------+--------------------+-----+-----+-------------+-----+------+
| START | Slave Address (7b) | R/W | ACK | Data Byte 1 | ACK | STOP |
+-------+--------------------+-----+-----+-------------+-----+------+
```

1. **START Condition (S)**: High-to-Low transition on `SDA` while `SCL` is High.
2. **Address Frame**: 7-bit slave address followed by a read/write bit (`0` = Write, `1` = Read).
3. **ACK / NACK**: The receiver pulls `SDA` low to acknowledge receipt of each byte.
4. **Data Frame**: 8 bits of data sent MSB first, followed by an ACK/NACK bit.
5. **STOP Condition (P)**: Low-to-High transition on `SDA` while `SCL` is High.
6. **Repeated START (Sr)**: A new START condition without releasing the bus with a STOP condition.

## Getting Started

1. Place your target firmware driver or hardware RTL files in `src/`.
2. Define bus parameters (clock frequency, address mode, pull-up sizing).
3. Verify operation using logic analyzers or simulation testbenches.
